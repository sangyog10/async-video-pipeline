🎬 Video Editor

Express Server with JWT Authentication

✅ Server is running successfully with JWT authentication!

🔐 Authentication Endpoints

POST /api/auth/register - Register new user
POST /api/auth/login - Login user
POST /api/auth/logout - Logout user

👤 User Endpoints (Protected)

GET /api/user - Get user info
PUT /api/user - Update user info

🎥 Video Endpoints (Protected)

GET /api/videos - Get user videos
POST /api/upload-video - Upload video
PATCH /api/video/extract-audio - Extract audio
PUT /api/video/resize - Resize video
GET /api/get-video-asset - Get video assets
🔑 Authentication Required: Include JWT token in Authorization header:
Authorization: Bearer <your_jwt_token>
